# Plataforma de Comunicação

Este repositório contém o projeto final da disciplina de **Estrutura de Dados II (ED2)** - 2025/2 do curso de Engenharia Informática.

## 📚 Tema
Desenvolvimento de uma plataforma de comunicação usando **estruturas de dados**, em especial **Hash Tables** e **Grafos**.

## 👨‍💻 Funcionalidades
- Cadastro de membros (Admin, Corporativo, Convidado)
- Login e autenticação
- Criação e gestão de equipas (públicas e privadas)
- Troca de mensagens entre membros e equipas
- Partilha de documentos
- Impressão de perfis e listagem de documentos
- Controlo de permissões com base no tipo de membro

## 🛠️ Tecnologias
- Linguagem: C
- Estruturas de Dados: Listas,Tabela Hash e Grafos

## 📁 Estrutura do Projeto
- `srcs/` — Código principal e implementações dos headers
- `includes/` — Cabeçalhos (headers .h)
- `data/` — Arquivos de entrada e saída
- `docs/` — Relatório e apresentação do trabalho

## 🧠 Objetivos
- Dominar os conceitos sobre estruturas de dados 
- Materializar os conceitos por meio de uma solução prática 
- Melhorar capacidade de interpretação de texto, escrita e oratória
